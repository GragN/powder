# Powder Lab

Первая версия физической песочницы в духе **The Powder Toy**, написанная на **C# / .NET 10 / Raylib**. Исходный код оригинальной игры не заимствован. Каждая ячейка симуляции отображается квадратом **2 × 2 пикселя**, без сглаживания. Поле — 480 × 336 ячеек, окно — 1280 × 800.

![Powder Lab](docs/screenshot.png)

Игра запускается с **пустым полотном**. Минималистичный интерфейс содержит палитру и основные инструменты; свойства материала открываются кнопкой **Properties** или клавишей `I`. Демонстрационная сцена загружается отдельно по `R` с подтверждением. Левая, правая и верхняя стороны открыты; твёрдым остаётся только дно.

## Запуск на Windows в VSCode

1. Установите [**.NET 10 SDK x64**](https://dotnet.microsoft.com/download/dotnet/10.0) — именно SDK, а не только Runtime. После установки перезапустите терминал VSCode.
2. Скачайте ZIP репозитория, распакуйте его и откройте **папку с `Powder.csproj`** через **File → Open Folder**.
3. В терминале этой папки выполните:

```powershell
dotnet run
```

Первый запуск загрузит Raylib-cs из NuGet. Нативная библиотека `raylib.dll` входит в пакет: устанавливать C++, Unity, SDL или отдельный Raylib не нужно. Нужны графический рабочий стол и драйвер с **OpenGL 3.3**. Окно не масштабируется, чтобы размер частиц оставался фиксированным; масштабирование Windows и физическая плотность экрана могут влиять на размер изображения на мониторе.

Для более высокой производительности:

```powershell
dotnet run -c Release
```

Для отладки установите расширение **C#** или **C# Dev Kit** и нажмите **F5**. Файлы `.vscode/launch.json` и `tasks.json` уже включены.

Оптимизация расчётов включена и для обычного `dotnet run`. Если для точной пошаговой отладки нужна неоптимизированная сборка, выполните `dotnet build -p:Optimize=false`; расчёт воздуха в такой сборке заметно медленнее.

## Что можно делать

- Рисовать песок, воду, камень, дерево, масло, соль, железо, медь, стекло, лёд, пар, дым, огонь и лаву.
- Строить сосуды и препятствия, смешивать жидкости, наблюдать оседание более плотных частиц.
- Нагревать и охлаждать материалы; при наведении видеть тип, температуру и массу частицы на верхней панели. Свойства выбранного материала доступны отдельно по `I`.
- Плавить лёд и металлы, превращать расплавленный песок в стекло после охлаждения, кипятить воду, конденсировать пар, поджигать дерево и масло, растворять соль.
- Наблюдать естественную конвекцию воздуха: тёплые струи поднимаются, холодный воздух опускается, дым и пар следуют за потоком. `T` показывает температуру материалов **и воздуха**, `A` — стрелки скорости.
- Ставить симуляцию на паузу, выполнять отдельные шаги и менять скорость.
- Сохранять сцену и восстанавливать её. По `R` можно загрузить демо с тремя стендами: гравитация и плотность, медный тепловой мост, горящее дерево.

| Управление | Действие |
|---|---|
| ЛКМ / ПКМ | Рисовать / стирать |
| Средняя кнопка мыши | Взять материал под курсором |
| Колесо мыши, `[` / `]` | Размер кисти |
| `1`–`9` | Быстрый выбор первых девяти материалов |
| `B`, `H`, `J` | Материал, нагрев, охлаждение |
| `Space`, `N` | Пауза, один шаг |
| `T`, `A`, `I` | Термокарта, потоки воздуха, свойства и включение атмосферы |
| `Ctrl+S`, `Ctrl+O` | Сохранить, загрузить |
| `C`, `R` | Очистить поле, загрузить демо; требуется подтверждение |
| `F1`, `Esc` | Справка, закрыть диалог |

Сцена сохраняется в `%LOCALAPPDATA%\PowderLab\scene.json`. Сохранение содержит материалы, массу, внутреннюю энергию, растворённую соль, скорости частиц, температуру и скорости воздуха; оно не является точкой точного воспроизведения генератора случайных чисел. Ошибка загрузки сохраняет текущий мир. Для своего файла: `dotnet run -- --scene "C:\Scenes\test.json"`.

Интерфейс игры пока на английском; инструкция на русском.

## Физическая модель и её границы

Это **первая игровая модель**, а не инженерный решатель гидродинамики. Справочные коэффициенты — приблизительные значения для типичных материалов около комнатной температуры. Они не моделируют конкретную марку сплава или температурную зависимость всех свойств.

- Физический масштаб: ячейка 2 мм × 2 мм, глубина среза 1 см; масса при создании равна `ρ × объём`. Гравитационное ускорение — 9,81 м/с², фиксированный шаг — 1/60 с. Масса переносится вместе с частицей и сохраняется при фазовых переходах, растворении и реакции горения. Рисование добавляет вещество, стирание удаляет его; любые движущиеся частицы исчезают после пересечения левой, правой или верхней границы. Дно непроницаемо. Масса и энергия вышедших частиц учитываются отдельно, оборачивания на противоположный край нет.
- В свободном падении порошков и жидкостей скорость растёт как `v = v₀ + gΔt`, а перемещение считается как `s = v₀Δt + gΔt²/2`. Дробная часть перемещения сохраняется. Общий предел скорости и ограничение четырьмя ячейками за шаг убраны: проверяется каждая пройденная ячейка, поэтому быстрые частицы не проходят сквозь тонкие стенки. На твёрдом препятствии вертикальная скорость гасится. Свободное ускорение не зависит от массы; разница плотностей определяет вытеснение в жидкостях. Течение и вязкость по-прежнему приближённые клеточные правила. Твёрдые стены неподвижны. Дым, пар и огонь подхватываются скоростью воздуха с конечным временем смешения, а не перемещаются вверх с заданной постоянной скоростью.
- Нагрев и охлаждение работают через **мощность 20 Вт на покрытую ячейку**: `Q = PΔt`, а вне фазовых переходов `ΔT = Q/(m × c)`. Одинаковая подведённая энергия даёт разный рост температуры у разных масс и теплоёмкостей. Время нагрева распределяется между точками штриха; изменение частоты кадров и количества промежуточных точек не умножает мощность. Инструмент работает и на паузе.
- Теплопроводность следует закону Фурье: `P = G × ΔT`, где `G = A / (dx/(2k₁) + dx/(2k₂))`. Тепловые сопротивления половин соседних ячеек складываются. Парный обмен решается с учётом `m × c` до ближайшей фазовой границы, затем продолжается с новыми свойствами и оставшимся временем. На участках скрытой теплоты температура остаётся постоянной. Переданная энергия вычитается из горячей частицы и добавляется холодной; выравнивание температур не создаёт перегрева. Два чередующихся тепловых прохода за шаг уменьшают погрешность последовательной обработки соседей. **Фиксированное остывание к 20 °C удалено.** Поверхности обмениваются энергией с соседними ячейками воздуха, имеющими конечную теплоёмкость. Потерянная материалом энергия добавляется воздуху; нагретый воздух может передать её другим материалам. Внутри замкнутого сосуда тепло не удаляется таймером.
- Вода использует энтальпию и скрытую теплоту плавления 334 кДж/кг и испарения 2256 кДж/кг, с плато 0 и 100 °C при атмосферном давлении. Изменение агрегатного состояния не пересоздаёт массу частицы. Объёмное расширение пара и сжимаемость не рассчитываются: весь объём частицы по-прежнему представлен одной ячейкой.
- Плавление меди, железа, камня, стекла и песка учитывает энергетический бюджет перехода. Расплав отображается как **Lava**. Медь и железо после охлаждения возвращаются в свой материал, а **песок превращается в стекло**, которое можно снова расплавить. Разницу теплоёмкостей песка и стекла учитывает сохраняемая точка отсчёта энтальпии: преобразование не добавляет энергию и не вызывает скачка температуры на границе затвердевания. Размягчение и стеклование кремнезёма представлены упрощённым переходом около 1700 °C; зависимость вязкости от температуры и отжиг пока не моделируются. Коэффициенты расплавов общие и приближённые.
- Горение — упрощённый источник химической энергии; доступ кислорода считается неограниченным. Масса топлива становится массой продуктов горения. Кинетика реакций и состав дыма приближённые. Нарисованный огонь — кратковременный источник зажигания; надёжнее нагреть топливо инструментом **Heat**.
- Соль переносится в раствор с сохранением массы и энергии, но изменение точки замерзания, кристаллизация соли, зависимость плотности рассола и химия растворов пока не реализованы. Гидростатическое давление жидкостей, ударные волны, сжимаемость воздуха, объёмное расширение пара и изменение концентрации кислорода остаются для следующих версий.

## Атмосфера и конвекция

Воздух — отдельное непрерывное поле, а не материал кисти. По умолчанию он невидим и имеет температуру 20 °C. Включите `T`, чтобы увидеть нагретые струи, и `A`, чтобы увидеть направление и скорость потока. При наведении на свободное пространство верхняя панель показывает **Air** и местную температуру; массы отдельной воздушной частицы у такого поля нет. Переключатель **Atmosphere** в свойствах отключает расчёт для сравнительных экспериментов; при обычном запуске он включён.

- Для скорости используется разнесённая MAC-сетка, перенос импульса, молекулярная вязкость и проекция давления, обеспечивающая приблизительную несжимаемость. Тепловая плавучесть рассчитывается через изменение плотности при нагреве: горячий воздух поднимается, холодный опускается. Перепады давления формируют боковой приток и возвратные течения вокруг нагретых областей.
- Тепло переносится консервативными потоками через грани ячеек; шаг переноса дробится по условию CFL. Есть также теплопроводность самого воздуха. Внутренний обмен не создаёт и не удаляет тепло. Температура 20 °C задаётся начальному состоянию и внешнему воздуху за открытыми краями; исходящий воздух уносит своё тепло. Поверхность материала непосредственно на открытом краю обменивается теплом с внешней атмосферой, и этот поток также учитывается как вышедшее тепло. Нижняя граница непроницаема и теплоизолирована.
- Параметры воздуха: плотность около 1,204 кг/м³, теплоёмкость 1005 Дж/(кг·К), теплопроводность 0,0257 Вт/(м·К), кинематическая вязкость 1,5×10⁻⁵ м²/с. В тепловом балансе хранится энергия воздуха относительно наружных 20 °C, а вышедшее тепло считается отдельно.
- Для работы в реальном времени воздушная ячейка покрывает **4×4 ячейки частиц** — примерно 8×8 мм. Геометрия препятствий консервативно округляется до этой сетки: узкие щели могут быть закрыты, зато струи не проходят сквозь тонкие стены. При занятии ячейки материалом накопленное тепло воздуха передаётся соседнему воздуху; неразрешимые замкнутые карманы сохраняют его до открытия. Оно не сбрасывается к комнатной температуре.

Модель описывает двумерную естественную конвекцию при малых скоростях с постоянными справочными коэффициентами. Расширение газов, акустика, излучение, турбулентность малых масштабов и превращение потерь кинетической энергии в тепло пока не рассчитываются. При очень высоких температурах плотность для плавучести — приближение.

Отдельная сцена для наблюдения конвекции: нагретая медная пластина и стеклянное препятствие над ней. Обычный запуск по-прежнему открывает пустое полотно.

```powershell
dotnet run -c Release -- --air-demo
```

## Проверки и сборка Windows

Проверки физики работают без окна и графического дисплея:

```powershell
dotnet run -c Release -- --self-test
```

Они проверяют ускорение и траекторию свободного падения, столкновения без прохождения сквозь препятствия, плотность, сохранение массы и энергии, мощность нагревателя, теплоёмкость, тепловое сопротивление, скрытую теплоту, цикл песок → расплав → стекло, плавление металлов, растворение, горение, сохранения и численную устойчивость демосцены, подъём и опускание воздуха, циркуляцию в закрытом сосуде, непроницаемость стен, тепловой баланс атмосферы и выход частиц через открытые края. Старые сцены загружаются; новые дополнительно сохраняют энергетическую точку отсчёта стекла, дробное перемещение и воздушное поле; у старых файлов атмосфера начинается с 20 °C. Ненулевой код возврата означает ошибку.

Короткий графический прогон с проверкой пустого старта, инструментов, панели свойств, очистки и сохранения:

```powershell
dotnet run -c Release -- --smoke-test --screenshot artifacts\smoke.png
```

Самостоятельная Windows x64 сборка, которая не требует установки .NET Runtime:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -o artifacts\windows
```

Запускайте `artifacts\windows\Powder.exe`. Для ZIP с готовой игрой **и исходниками, включая `.csproj`**, выполните:

```powershell
powershell -File scripts\package-windows.ps1
```

Результат: `artifacts\PowderLab-0.1.0-windows-x64.zip`. Скрипт запускается с обычной политикой выполнения локальных PowerShell-скриптов.

## Структура

`Simulation/` — независимая от графики физика и формат сцены; `UI/` — окно, инструменты и отрисовка; `Tests/` — запускаемые проверки; `Assets/` — шрифт с лицензией. Проект также собирается на Linux x64 и macOS x64/ARM64; нужны библиотеки рабочего стола и OpenGL. На Debian/Ubuntu обычно достаточно `libgl1 libx11-6 libxrandr2 libxinerama1 libxcursor1 libxi6` и активного дисплея.
