# Оптимизация расчетного ядра

Сравнение изолирует пять изменений вычислительного ядра относительно коммита
`c297936c28336503d0c9323ea44a989dcd12dd7f`. В обеих версиях одинаковые исходные сцены
и прежняя модель испарения. Новая физика испарения и изменения интерфейса в это
сравнение не входят.

## Изменения

- Для внутренней грани материала без контакта с воздухом больше не вычисляются
  температура и теплопроводность.
- Первый проход предобусловливателя давления от нулевой коррекции использует
  только нижний треугольник. Не нужны предварительное обнуление коррекции и чтение
  соседей, которые в этом проходе заведомо равны нулю.
- Площади граней для усреднения скоростей, теплоемкости объемов и веса диагностической
  сетки вычисляются при перестроении геометрии и используются во всех подшагах.
- Внутри одного шага переноса импульса тепло не меняется: соответствующее ускорение
  плавучести вычисляется один раз для каждой грани и повторно используется.

Шаг времени, разрешение сеток, коэффициенты и критерии сходимости не менялись.

## Измерения

.NET 10.0.402, Release, Linux x64, поле 320 × 224. Использован существующий
`--benchmark`: 30 шагов прогрева и 180 измеряемых шагов на сцену.
Для каждой строки ниже приведена медиана среднего времени шага в трех запусках.
Положительное значение последнего столбца означает уменьшение времени.

| Режим | Сцена | До, мс/шаг | После, мс/шаг | Уменьшение времени |
|---|---|---:|---:|---:|
| Обычный запуск | `empty` | 0.376 | 0.358 | +4.9% |
| Обычный запуск | `water-boiling` | 12.365 | 12.634 | -2.2% |
| Обычный запуск | `demo` | 29.424 | 28.276 | +3.9% |
| Без tiered JIT | `empty` | 0.206 | 0.252 | -22.6% |
| Без tiered JIT | `water-boiling` | 13.360 | 12.039 | +9.9% |
| Без tiered JIT | `demo` | 34.348 | 30.590 | +10.9% |

У хоста был существенный разброс: например, отдельный прогон `demo` без tiered JIT
занял 102.47 мс/шаг, а соседние прогоны той же сборки — 28.95–30.59 мс/шаг.
Обычная сцена кипения не показала устойчивого выигрыша; улучшение всех сцен или
фиксированный прирост FPS эти данные не доказывают. Дополнительные два парных
запуска на одном CPU также сохранены без удаления выбросов.

Это измерение физического шага без графического окна. Время кадра дополнительно
зависит от отрисовки, количества шагов за кадр, драйвера и ограничения 60 FPS.
Все исходные отчеты находятся в [performance-kernel-optimization.json](performance-kernel-optimization.json).

Это замеры промежуточного этапа, до добавления разреженного пара и микрокапель.
Текущие версии `AirField.cs` и `AirGeometry.cs` уже содержат поддержку новой модели,
поэтому простое копирование этих файлов в старый коммит не воспроизводит изоляцию.
Для сравнения всей итоговой версии с исходной используйте команды и отчеты в
[EVAPORATION-PERFORMANCE.md](EVAPORATION-PERFORMANCE.md).

## Проверка сохранения физики

В изолированной оптимизированной версии прошли все 91 существующий тест. После
210 шагов каждой из трех benchmark-сцен полные JSON-сохранения до и после
оптимизации совпали побайтно, включая частицы, пузырьки, энергию, скорости и поля
жидкости/воздуха. Хеши сохранений включены в исходный отчет. Сохранение для этого
сравнения выполнялось после завершения измеряемого участка.
